# ParaBank Manual QA Testing Project

## Project Overview

This project demonstrates a manual software testing process performed against the ParaBank demo banking application.

The project focuses on applying software testing principles to realistic banking workflows, including authentication, account management, fund transfers, bill payments and transaction history.

## Objectives

* Identify and document functional requirements.
* Design and execute manual test scenarios and test cases.
* Identify and document software defects.
* Apply risk-based testing principles.
* Maintain requirements-to-test traceability.
* Produce professional QA documentation.
* Evaluate the application's readiness based on test results.

## Application Under Test

**Application:** ParaBank Demo Bank

**Testing Type:** Manual Functional Testing

**Environment:** Web Application

**Primary Browser:** Chrome

## Testing Scope

The initial testing scope includes:

* Customer registration
* Customer login
* Forgot login information
* Account management
* Account overview
* Fund transfers
* Bill payments
* Transaction history
* Loan functionality
* Logout

Navigation and informational pages will also be reviewed as part of basic navigation testing.
